🎓 EBAC — Módulo 21: Gerenciador de Livros

## 📖 Sobre

Aplicação de gerenciamento de livros:

- `src/components/BookForm.tsx` — formulário de cadastro
- `src/components/BookItem.tsx` / `bookList.tsx` — listagem
- `src/services/Api.ts` — consumo de API
- `src/types/Book.ts` — tipagem do modelo

## 🚀 Como rodar

```bash
npm install
npm run dev
```

## 🛠️ Tecnologias

React • TypeScript • Vite

## 💡 O que aprendi

- Formulários controlados e tipagem de modelos
- Separação de responsabilidades (componentes × serviço de API)
